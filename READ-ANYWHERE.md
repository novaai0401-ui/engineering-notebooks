# Read anywhere

Choose the edition that suits the situation. These files contain the current library; existing content-depth and production-verification limits remain.

| Edition | What you receive | How to read |
| --- | --- | --- |
| [GitHub](github/README.md) | 33 Markdown notebooks with code and Previous/Next links | Open in the repository; private repository access is required |
| [Full PDF](output/pdf/engineering-notebooks-complete.pdf) | All 33 notebooks, bookmarked chapters and static experiment appendix | Download and open in a PDF reader; use bookmarks or linked contents |
| [EPUB](output/engineering-notebooks.epub) | Reflowable text, code, tables and a navigable contents list | Download and import into an EPUB-compatible reader; adjust its text size |
| [LinkedIn carousel](output/pdf/linkedin-checkpoints-and-retries.pdf) | Nine pages: a question, worked failure, prediction, answer and takeaway | Download and attach as a document post if you choose; nothing has been posted automatically |
| [Interactive HTML](index.html) | Themes, simulations, notes and progress | Download the whole package and open index.html or run the study server |

## What changes across formats

PDF and EPUB do not run JavaScript. The [static experiment appendix](output/STATIC-EXPERIMENTS.md) preserves the numerical examples and explanations. Printed code may wrap visually; use the included source files to execute it. Lab execution still requires the documented runtimes. Links to external source code or services need network access, but the lesson text is included.

Reading progress and notes in HTML stay in that browser; they do not synchronize to PDF or EPUB. Reader apps differ in handling tables, code wrapping, themes and links. No single format works in literally every app. The EPUB is designed for compatible reflowable readers; the PDF preserves its fixed page layout.

## Sharing responsibly

The GitHub repository is private. A repository URL does not grant access. Share downloaded files directly with your intended audience, or grant repository access separately. The carousel is a short companion about checkpoints and retries, not a claim that nine pages teach the entire curriculum.
